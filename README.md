### Лабораторна робота №1



##### "Імплементація та маніпуляції основними типами та структурами даних у Python"



* ###### Опис проєкту



Проєкт містить програмну реалізацію завдань лабораторної роботи, присвяченої основним типам і структурам даних мови програмування Python.



* ###### Структура та зміст роботи



У межах лабораторної роботи реалізовано п'ять завдань:



1\. Списки (Lists) — індексація, зрізи, додавання, зміна та видалення елементів.

2\. Кортежі (Tuples) — створення кортежів, розпакування, обчислення середнього бала та перевірка незмінності.

3\. Словники (Dictionaries) — підрахунок частоти слів, безпечне отримання значень і сортування даних.

4\. Множини (Sets) — усунення дублікатів, об'єднання, перетин, симетрична різниця та перевірка підмножин.

5\. Дослідження часової складності - вимірювання та порівняння ефективності пошуку й видалення дублікатів у структурах даних різного розміру.

Для запуску програми необхідно:

\- мати встановлений Python версії 3.14.10;
